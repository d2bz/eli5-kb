# eli5-kb

一个 [Claude Code](https://claude.com/claude-code) skill：和 Claude 结对，把你正在啃的项目逐步做成一座「大图少字」的本地图解知识库。

它长出来的不是一堆聊天记录，而是一个能点开慢慢逛的静态站：入口索引 → 分类卡片 → 一级全景页 → 层层下钻的细节子页。每一页都是深色大字卡片风，生活化比喻开场，机制流程用 emoji 画出来，页脚交叉链接组网——接近个人 wiki / digital garden 的形态。

## 为什么不直接问 Claude 就好

问完就忘。这个 skill 把「问懂一个概念」变成「库里多一页」，并且强制两条纪律：

- **读代码取证**：每张卡片的事实必须能在代码里指认（带 `文件:行号`），不许凭印象写。注释里的事故编号、灰度开关、取舍理由会被挖出来做成「⭐ 亮点备忘卡」——面试/汇报时值得讲、且经得起追问的那种材料。
- **层级纪律**：一级页进索引，细节子页只从父页卡片下钻、不污染索引。库长大了依然逛得动。

## 长什么样

```
learn-html/                        ← 独立于 git 仓库，纯本地
├── index.html                     ← 入口：分类卡片网格
├── 00-architecture/
│   ├── eli5-整体架构.html          ← 一级页（进 index，标"可下钻"）
│   ├── eli5-子架构-任务调度.html    ← 子页（从全景页下钻）
│   └── eli5-重试与退避.html        ← 孙页（从任务调度页下钻）
├── 01-storage/
├── 02-cache/
│   └── eli5-缓存淘汰.html
└── ...                            ← 两位数字前缀分类，按项目模块划分
```

单页的内容套路：**一句话比喻**（"上次剪头的 Tony 还记得你的头型"——粘性会话）→ **为什么**（双卡对比）→ **机制流程**（写门/读门/清除，emoji 场景卡串联）→ **易混淆邻居对比** → **⭐ 亮点备忘**（每条带真实事故编号或设计取舍）。

## 安装

把本仓库内容放进 Claude Code 的用户级 skills 目录：

```bash
# macOS / Linux
git clone https://github.com/d2bz/eli5-kb ~/.claude/skills/eli5-kb

# Windows (Git Bash)
git clone https://github.com/d2bz/eli5-kb /c/Users/<你>/.claude/skills/eli5-kb
```

新开会话即可用（skill 名：`eli5-kb`）。

## 怎么用

### 新项目（还没有库）

直接说：

> /eli5-kb 帮这个项目建一座学习库

Claude 会走初始化流程：

1. 问你库放哪（建议项目旁的独立目录，不进 git）
2. 扫项目 README / 目录结构，**提出 6~9 个分类给你增删确认**——分类是你的心智地图，它不替你定
3. 用 `templates/index.html` 生成入口骨架，分类卡全部「（待生成）」占位
4. 从「整体架构」全景页起步——先有地图，后续主题才有地方下钻
5. 把库位置写进项目记忆，下次会话自动找到

### 已有库的项目

日常就三类说法：

- 「把 **连接池** 做成图解页」——新主题，Claude 自己判断进哪个分类、是一级页还是子页
- 「**下钻** XX 页里的 YY 概念」——在父页对应卡片下长出子页，双向挂链
- 「讲讲 XX」——对话里讲一遍要点（带 `文件:行号`），页面归档一份慢慢复习

层级两可、分类模糊时 Claude 会问你，不默默选。

### 换项目复用

每个项目一座库，互不干扰：库位置存在各项目自己的 Claude 记忆里，skill 本身是通用的。换新项目第一次用会自动走初始化。
